# Security Policy

## Reporting a Vulnerability

If you find a security vulnerability in Komplyt Zero, please email **security@kompl.yt**.

Please include:
- Description of the vulnerability
- Steps to reproduce
- Potential impact
- Any suggested fixes (optional)

We will acknowledge receipt within 48 hours and provide an initial assessment within 5 business days.

## Scope

This policy covers:
- The Komplyt Zero codebase (this repository)
- The hosted service at kg.kompl.yt

Out of scope:
- Third-party dependencies (report to their maintainers)
- Social engineering attacks
- Denial of service attacks

## Disclosure

We follow coordinated disclosure. Please give us reasonable time to fix an issue before you disclose it publicly. We will credit you in the release notes unless you prefer to remain anonymous.

## Security Updates

Security fixes are released as patch versions. To be notified, subscribe to this repository's releases on GitHub.
